## Implementation Notes

### filter_links()
- Drops mailto: and anchor-only (#) links up front before URL parsing
- Strips `www.` prefix before checking against `_SKIP_DOMAINS` (github.com, youtube.com, reddit.com)
- Pattern list covers unsubscribe, opt-out, social share intents (twitter/intent, facebook/sharer, linkedin/shareArticle), and tracking redirect patterns from processor.py plus mailchimp.com broadly
- Returns a plain list; deduplication happens in `fetch_articles()` so `filter_links()` stays a pure filter

### detect_paywall()
- HTTP 402 / 403 short-circuits immediately before string scanning
- Phrases checked on lowercased HTML: "subscribe to read", "sign in to continue", "premium content", "paywall", "members only"

### extract_article_text()
- Uses BeautifulSoup with "lxml" parser (already a dependency)
- Strips script, style, nav, footer, aside, header tags before text extraction
- Title: prefers `<title>` tag, falls back to first `<h1>`
- Strips site-name suffixes with regex `\s*[|\-–—]\s+.+$` on the title
- Text truncated to 500 chars (hard slice, no word-boundary truncation per spec)
- Returns ("", "") on any exception or empty input

### fetch_articles()
- Collects (url, email_index) pairs with 1-based email indexing
- Deduplicates URLs across all emails; first-seen email_index wins
- Caps at 10 URLs before fetching
- User-Agent: "Mozilla/5.0 (compatible; EmailDigestBot/1.0)"
- httpx.get with timeout=10.0s, follow_redirects=True
- Skips non-HTML responses via Content-Type check ("text/html" substring)
- All per-URL exceptions caught and logged at WARNING; processing continues
- ArticleContent is imported from models.py (already present, added by architect)
