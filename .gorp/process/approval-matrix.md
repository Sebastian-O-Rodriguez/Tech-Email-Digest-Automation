# Approval Matrix

## Auto-Approved (any agent)

- Write/modify source code within assigned scope
- Run tests and quality gates
- Create git branches
- Write journal entries
- Read any project file

## Robo Decides

- Re-prioritize tasks within a sprint
- Reassign tasks between agents
- Skip low-priority tasks
- Extend sprint scope (minor additions)

## CTO Required

- Modify `CLAUDE.md` or `roadmap.md`
- Add new dependencies to `pyproject.toml`
- Change data model / contracts in `models.py`
- Modify GitHub Actions workflow
- Change environment variables or secrets
- Modify auth configuration
- Deploy or release
- Change agent definitions
